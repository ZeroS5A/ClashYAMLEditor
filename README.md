# Clash YAML Editor

面向 OpenWrt / OpenClash、独立 Mihomo 和 Smart 内核的浏览器配置编辑器。React + Vite 构建，配置解析、编辑、二维码和导出在本地完成。构建产物包含 JavaScript、CSS 和 YAML 工作线程，可部署到静态服务器；不是单文件应用。

## 使用

1. 导入 YAML 文件或粘贴配置。解析器随应用打包，无需 CDN。结构无效时保留原配置，成功后进入配置体检。
2. 在基础设置选择实际部署方式、内核类别及版本。版本用于记录；校验目前按内核类别进行，不提供逐版本功能矩阵。
3. 编辑节点、策略组和规则；DNS、透明代理与 TUN、代理集合位于“高级设置”的二级菜单。高级字段通过 JSON 编辑并保留；组的 use 可引用代理集合。
4. 可按需查看配置体检，定位配置问题；体检不是导出的前置步骤。
5. 在“导出配置”点击“复制 YAML”，粘贴到 OpenClash 中使用；也可点击“下载 YAML”保存为 config.yaml。复制和下载始终使用下方文本原样，无需应用，检查提示不会阻止导出。
6. 导出页可手动修改 YAML（不会同步到其他编辑页面）。若之后在其他页面改了配置，会提示内容差异，可选择恢复编辑器中的最新配置。OpenClash 可能覆写模式、端口、DNS、TUN，请检查最终运行配置。

## 数据完整性和交互

- 节点、策略组、Provider 的未知字段保留；无修改保存不会注入测速、网络默认值。导入只补齐编辑器必需的空集合。
- 重命名、删除会更新组成员、MATCH / 组合规则、子规则、dialer-proxy、Provider 下载出站、DNS 和 TUN 的相应引用。删除会说明引用处理，可撤销恢复。
- 撤销／重做保存最近 60 次编辑，撤销后新编辑会清除旧重做分支。输入框及弹窗内保留文本编辑快捷键。
- 规则解析支持嵌套逻辑表达式，复杂规则可编辑原文。新增规则及普通规则置底会插入 MATCH 前。
- mrs 与 classical 的无效组合会被阻止；编辑 Provider 不会自动修改已有文件路径后缀。
- 弹窗支持 Escape、焦点约束和关闭后的焦点恢复。小屏使用功能选择菜单。

## 导入、订阅及分享

- 分享链接支持 SS、SSR、VMess、VLESS、Trojan、Hysteria2、TUIC；处理 UTF-8、IPv6、编码凭证、WS/gRPC、SNI、指纹、ALPN、Reality 和常见插件选项。
- 分享链接无法表达全部 Mihomo 字段。分享面板显示可能丢失的字段，可复制完整 YAML 节点片段。
- 订阅支持 URI 列表、Base64 和静态节点 YAML，先预览再导入；同名节点可更新、保留双方或仅添加新名称。更新保留原节点额外字段和自定义组、规则。
- 请求默认 15 秒超时，最多 3 个订阅并发，支持取消；文本／文件限 20 MiB。浏览器仍受 CORS、混合内容及证书限制。
- SubConverter 会把订阅及其中凭证发送到指定后端，界面会明确提示；跳过证书验证默认关闭。推荐在可信后端转换。
- YAML 注释和原始排版不保留；循环别名、超过 100 层嵌套和过大的别名展开会拒绝导入。

## 性能与草稿

YAML 解析、序列化和订阅解析在 Worker 中进行。节点、策略组、规则、导入预览及组成员列表使用虚拟列表；策略组列表占用内容区剩余高度，ResizeObserver 在窗口缩放时更新可视范围。订阅合并和名称冲突统计使用 Map，避免逐项重复扫描。

草稿延迟 600 毫秒写入浏览器存储，不在每次渲染时序列化整个配置。导出页手动修改的 YAML 也会保存。存储失败会显示错误并可重试；未保存时提示离开。草稿可能包含密码、订阅地址和令牌；取消“记住草稿（含凭证）”会删除已有本地草稿并关闭自动保存。

## 开发与验证

使用 Node.js 22.12+ 和 Yarn 1：

```sh
yarn install --frozen-lockfile
yarn dev
yarn check
yarn test:browser
```

也可以使用 npm 运行上述脚本。构建输出为 dist，资源使用相对路径。浏览器测试默认使用系统 Edge，可通过 PLAYWRIGHT_CHANNEL 指定 chrome 或其他已安装的 Playwright 通道。

核心回归测试覆盖字段往返、结构与别名拒绝、历史分支、7 种协议分享往返、复杂规则引用、订阅合并、诊断和网络边界。浏览器回归覆盖窗口缩放／移动端、2,000 个策略组、50,000 条规则、实际编辑与撤销、离线 YAML、源码／复制／下载一致性、配额错误及草稿恢复。

静态体检不会下载所有 Provider 内容，也不会连接路由器执行内核启动校验。
